# Provider workflow catalog

Load only the workflow relevant to the current request.

- [archivebox-kg-ingestion](../../archivebox-kg-ingestion/WORKFLOW.md): Natively ingest an ArchiveBox archive into the epistemic-graph knowledge graph via the archivebox-api MCP server — push snapshots as typed :Snapshot nodes (with :Tag + :hasTag links and per-snapshot :Document page-text) and archive results as :ArchiveResult nodes, best-effort, with the Wire-First ingest tools. Use when the agent must make the web archive queryable/semantic-searchable in the KG, backfill existing snapshots, or wire a recurring sync. Do NOT use for adding/re-archiving URLs (archivebox-web-archiving) or plain read/search of the archive (archivebox-snapshot-search); prefer those.
- [archivebox-snapshot-search](../../archivebox-snapshot-search/WORKFLOW.md): Browse and search an ArchiveBox archive via the archivebox-api MCP server — list/filter snapshots, read one snapshot (with its per-extractor archive results), list archive results by extractor/status, and read tags with the domain-typed core tool. Use when the agent must find an archived URL, inspect what was captured for a page, check extractor success/failure, or resolve a snapshot/result/tag by its abid. Do NOT use for adding or re-archiving URLs (archivebox-web-archiving) or for pushing data into the knowledge graph (archivebox-kg-ingestion); prefer those.
- [archivebox-web-archiving](../../archivebox-web-archiving/WORKFLOW.md): Capture and re-archive web pages with ArchiveBox via the archivebox-api MCP server — add URLs (with tags, crawl depth, and chosen extractors), update / re-archive existing snapshots, and schedule recurring archiving with the domain-typed CLI tool. Use when the agent must permanently archive a URL, bulk-add a list of links, refresh stale captures, or set up a recurring archive job. Do NOT use for browsing/searching what is already archived (archivebox-snapshot-search) or for pushing archived data into the knowledge graph (archivebox-kg-ingestion); prefer those.
